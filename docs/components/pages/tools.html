Tool Definitions

Create tool definitions with mining levels, click requirements, durability costs, and linked drop tables.

Tools bridge blocks and drops. Each tool action maps a specific item material and click type to a number of clicks needed, durability cost, and which drop tables are used. Tool files are stored in the tools/ folder and referenced by block definitions.

Tool resolution happens at runtime: MMOBlock checks the player's held item material, finds the matching tool action, and applies the corresponding click requirement, durability, and drops.

1. File Structure #

Each file in plugins/MMOBlock/tools/ defines a tool group. A tool group is a list of tool actions that share a logical purpose (e.g., "pickaxes" or "axes"). The file name is the tool group ID used in block definitions.

# tools/exampleTools.yml exampleTools: - material: DIAMOND_PICKAXE both_click: decreaseDurability: 15 clickNeeded: 4 allowedDrops: - exampleDrops - material: NETHERITE_PICKAXE left_click: decreaseDurability: 10 clickNeeded: 3 allowedDrops: - exampleDrops - material: NETHERITE_PICKAXE right_click: decreaseDurability: 10 clickNeeded: 3 allowedDrops: []

2. Click Types #

Each tool action defines the click type it responds to. This allows different behaviors for left-click vs. right-click with the same item.

Click Type Key Description
Both both_click Matches both left and right clicks. Use for simple mining tools.
Left Click left_click Matches only left-click interactions.
Right Click right_click Matches only right-click interactions.

You can define multiple tool actions for the same material but different click types, as shown in the example above. A single tool group entry can have only one click type key.

3. Tool Action Options #

Option Type Description
material Material The Bukkit material the player must be holding (e.g., DIAMOND_PICKAXE, NETHERITE_PICKAXE).
clickNeeded Integer Number of clicks required to break the block with this tool.
decreaseDurability Integer Durability damage applied to the tool per click.
allowedDrops List List of drop table IDs that apply when this tool is used. Can be empty for no drops.

4. Tool Resolution Logic #

When a player clicks a block, MMOBlock resolves the correct tool action using this logic:

  1. MMOBlock reads the block's allowedTools list to find matching tool group IDs.
  2. For each tool group, it iterates the tool actions looking for the first entry where material matches the held item and click type matches the interaction (left click, right click, or both).
  3. The first matching tool action is used. Its allowedDrops determine the drop table, and clickNeeded / decreaseDurability control the mining experience.

This design means you can create different mining experiences for different tiers of tools without duplicating drop tables.

5. Full Example #

A complete tool group with multiple materials and click types:

# tools/exampleTools.yml — Pickaxe tool group exampleTools: # Diamond pickaxe: 4 clicks, both left and right work, 15 durability per click - material: DIAMOND_PICKAXE both_click: decreaseDurability: 15 clickNeeded: 4 allowedDrops: - exampleDrops # Netherite pickaxe: 3 clicks left-click only, 10 durability per click - material: NETHERITE_PICKAXE left_click: decreaseDurability: 10 clickNeeded: 3 allowedDrops: - exampleDrops # Netherite pickaxe right-click: same material, different click type, no drops - material: NETHERITE_PICKAXE right_click: decreaseDurability: 10 clickNeeded: 3 allowedDrops: []
