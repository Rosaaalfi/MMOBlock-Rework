Node Entities

Placeable node entities that manage multiple block spawns within a radius, with status holograms showing block availability.

Nodes are advanced interactive entities that act as "managers" for custom blocks. Unlike standalone blocks which are placed individually, a node spawns and manages multiple child blocks within a defined radius. Each node displays a hologram showing which child blocks are active or respawning. Nodes are defined in the nodes/ folder and placed via the /mmoblock node place command.

Node child blocks are normal block definitions from the blocks/ folder. The node references them via the listBlocks field.

1. File Structure #

exampleNodes: item: name: "&7Example Nodes" material: iron_ore listBlocks: - exampleEntityNodes maxBlocks: 4 randomLocation: enabled: true radius: 3 closest: true center: 1 blockList: dead: "&7- &f{block_name} {respawn_times}s" active: "&7- &f{block_name} &aActive" display: displayHeight: 2.1 lines: - line: 1 contents: item: minecraft:diamond - line: 2 contents: text: "<anim:wave:&1;&b>Plains Nodes 1</anim>"

2. Item Configuration #

The item section defines the item representation for the node (used in the admin placement tool).

Option Type Description
name String Display name with & color codes.
material Material Bukkit material for the item icon.

3. Referenced Blocks #

The listBlocks field lists block definition IDs from the blocks/ folder. The node randomly selects from this list when spawning new child blocks.

Option Type Description
listBlocks List Block definition IDs that this node can spawn as children.
maxBlocks Integer Maximum number of concurrently active child blocks.

4. Spawning & Random Location #

Control where child blocks appear relative to the node center.

Option Type Default Description
randomLocation.enabled Boolean false Enable random spawn placement.
randomLocation.radius Integer — Horizontal radius for random placement.
randomLocation.closest Boolean false Only spawn adjacent to solid blocks on N/S/E/W sides.
randomLocation.center Integer — Minimum horizontal distance from the node hologram center.

5. Display Hologram #

Nodes display a hologram above the node location showing the node name and a list of active/dead child blocks. The block list is auto-populated using the {block_lists} placeholder.

Option Type Description
displayHeight Double Height of the hologram above the node center.
lines List Hologram lines (same format as block display lines).
blockList.dead String Template for dead/respawning blocks in the list. Supports {block_name} and {respawn_times}.
blockList.active String Template for active (mined) blocks in the list. Supports {block_name}.

Block list placeholders:

  • {block_lists} — Auto-populated list of all child blocks with their status.
  • {block_name} — The display name of the child block.
  • {respawn_times} — Remaining respawn time for dead blocks.

6. Commands #

Nodes are managed via the admin commands:

# Place a node at your location /mmoblock node place <nodeId>
# Remove a node at your location /mmoblock node remove
# List all nodes /mmoblock node list
# Get the node tool /mmoblock node get <nodeId>
