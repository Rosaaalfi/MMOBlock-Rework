Drop Tables

Configure drop tables with items, experience, commands, and random distributions for your custom blocks.

Drop tables define what happens when a player mines a block. Each entry specifies either an item, experience points, or a console command with individual chances and quantities. Drop tables are stored in the drops/ folder and referenced by tool definitions.

Drops are resolved through tools: a block's allowedTools references tool groups, and each tool action lists allowedDrops which reference drop table IDs.

1. File Structure #

Each file in plugins/MMOBlock/drops/ contains a single drop table — a list of drop entries. The file name (without .yml) is the drop table ID used in tool definitions.

# drops/exampleDrops.yml exampleDrops: - material: iron_ingot total: [ 1-2 ] chances: 0.4 drop_type: inventory - experience: [ 10-20 ] chances: 0.5 drop_type: front_ground - command: "give %player% minecraft:diamond 5" chances: 0.1

2. Item Drops #

Item drops give the player a specific Minecraft item. You can define a quantity range and probability.

Option Type Description
material Material Bukkit material to drop (e.g., iron_ingot, diamond).
total Range Quantity range as [min-max]. A random value in this range is selected per drop.
chances Double Probability of this drop occurring, from 0.0 (0%) to 1.0 (100%).
drop_type String Where the item appears. See Drop Location Types.
exampleDrops: - material: iron_ingot total: [ 1-2 ] chances: 0.4 drop_type: inventory - material: diamond total: [ 1-1 ] chances: 0.05 drop_type: front_ground

3. Experience Drops #

Experience drops grant XP orbs directly to the player or spawn them at the block location.

Option Type Description
experience Range Experience point range as [min-max].
chances Double Probability from 0.0 to 1.0.
drop_type String Where the XP orbs appear.
exampleDrops: - experience: [ 10-20 ] chances: 0.5 drop_type: front_ground

4. Command Drops #

Command drops execute a console command when the block is mined. Use %player% as a placeholder for the mining player's name.

Option Type Description
command String Console command to execute. Use %player% for the player name.
chances Double Probability from 0.0 to 1.0.
Commands run with console privileges. Avoid giving unsafe commands in drop tables that could be exploited.
exampleDrops: - command: "give %player% minecraft:diamond 5" chances: 0.1 - command: "eco give %player% 100" chances: 0.05

5. Drop Location Types #

The drop_type field controls where dropped items or XP orbs appear:

Value Description
inventory Items/XP are added directly to the player's inventory. If the inventory is full, items drop on the ground at the player's location.
front_ground Items/XP spawn on the ground in front of the block.
center_ground Items/XP spawn on the ground at the center of the block.

6. Full Example #

A complete drop table combining all entry types:

# drops/exampleDrops.yml — mixed drop table exampleDrops: # Common item drop (40% chance, 1-2 iron ingots) - material: iron_ingot total: [ 1-2 ] chances: 0.4 drop_type: inventory # Rare item (5% chance, single diamond) - material: diamond total: [ 1-1 ] chances: 0.05 drop_type: front_ground # Experience drop (50% chance, 10-20 XP) - experience: [ 10-20 ] chances: 0.5 drop_type: front_ground # Command drop (10% chance, gives 5 diamonds via command) - command: "give %player% minecraft:diamond 5" chances: 0.1
