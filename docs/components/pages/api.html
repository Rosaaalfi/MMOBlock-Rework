2. Adding the API #

MMOBlock API is published to the Chyxel Repository. Add the repository and dependency to your build script:

repositories { maven { url = uri("https://public-repo.chyxelmc.me/repository") } } dependencies { compileOnly("me.chyxelmc:mmoblock-api:{{VERSION}}") }
<repository> <id>chyxel-repo</id> <url>https://public-repo.chyxelmc.me/repository</url> </repository> <dependency> <groupId>me.chyxelmc</groupId> <artifactId>mmoblock-api</artifactId> <version>{{VERSION}}</version> <scope>provided</scope> </dependency>
Use compileOnly (Gradle) or provided (Maven) scope. MMOBlock loads its own API implementation at runtime — embedding the API jar in your plugin will cause class conflicts.

3. API Entry Point #

All API access starts from MMOBlockApi:

package me.chyxelmc.mmoblock.api; public interface MMOBlockApi { @NotNull BlockService getBlockService(); @Nullable NodeService getNodeService(); @Nullable static MMOBlockApi get(); }

Usage in your plugin:

import me.chyxelmc.mmoblock.api.*; MMOBlockApi api = MMOBlockApi.get(); if (api == null) { // MMOBlock is not loaded return; } BlockService blocks = api.getBlockService(); NodeService nodes = api.getNodeService(); // may be null

The plugin registers itself with ApiProvider.register(apiImpl) during onEnable(). Consumers call MMOBlockApi.get() to obtain the singleton instance.

4. Services #

BlockService

Full CRUD for placed blocks. Package: me.chyxelmc.mmoblock.api.service

public interface BlockService { // Definition lookup BlockDefinition getBlockDefinition(String id); Set<String> getBlockIds(); // Placed block queries Collection<? extends PlacedBlock> getPlacedBlocks(); PlacedBlock getPlacedBlock(UUID uniqueId); List<? extends PlacedBlock> findBlocksByType(String type); List<? extends PlacedBlock> findBlocksInWorld(String worldName); // Place / remove PlaceResult placeBlock(String type, World world, double x, double y, double z, String facing); boolean removeBlock(String type, World world, double x, double y, double z); boolean removeBlock(UUID uniqueId); boolean removeBlockByInteractionEntity(Entity entity); // Player sync void syncFakeBlocksForPlayer(Player player); boolean isPlayerLookProtected(Player player); }

NodeService

Full CRUD for placed nodes. Package: me.chyxelmc.mmoblock.api.service

public interface NodeService { // Definition lookup NodeDefinition getNodeDefinition(String id); Set<String> getNodeIds(); // Placed node queries Collection<? extends PlacedNode> getPlacedNodes(); Collection<? extends PlacedNode> findNodesByType(String nodeId); Collection<? extends PlacedNode> findNodesInWorld(String worldName); // Place / remove NodePlaceResult placeNode(String nodeId, World world, double x, double y, double z); boolean removeNode(String nodeId, World world, double x, double y, double z); boolean removeNodeByBlockUniqueId(UUID blockUniqueId); // Player sync void syncForPlayer(Player player); }
MMOBlockApi.getNodeService() may return null if the node runtime is unavailable. Always null-check before using.

5. Events #

All event classes are in package me.chyxelmc.mmoblock.api.event.

BlockPlaceEvent

Fired when a block is placed. Extends PlayerEvent implements Cancellable.

public class BlockPlaceEvent extends PlayerEvent implements Cancellable { public BlockPlaceEvent( @Nullable Player player, @NotNull PlacedBlock placedBlock, @NotNull BlockDefinition definition ); // Getters @NotNull PlacedBlock getPlacedBlock(); @NotNull BlockDefinition getDefinition(); // Cancellable boolean isCancelled(); void setCancelled(boolean cancelled); // Handler list @NotNull HandlerList getHandlers(); static HandlerList getHandlerList(); }

BlockMineEvent

Fired when a player mines a block. Extends PlayerEvent (not cancellable).

public class BlockMineEvent extends PlayerEvent { public BlockMineEvent( @NotNull Player player, @NotNull PlacedBlock placedBlock, @NotNull BlockDefinition definition, @NotNull String clickType, int currentProgress, int maxProgress, boolean completed ); // Getters @NotNull PlacedBlock getPlacedBlock(); @NotNull BlockDefinition getDefinition(); @NotNull String getClickType(); int getCurrentProgress(); int getMaxProgress(); boolean isCompleted(); // Handler list @NotNull HandlerList getHandlers(); static HandlerList getHandlerList(); }

BlockRemoveEvent

Fired when a block is removed from the world. Extends PlayerEvent (not cancellable). Player may be null if removed programmatically.

public class BlockRemoveEvent extends PlayerEvent { public BlockRemoveEvent( @Nullable Player player, @NotNull PlacedBlock placedBlock ); // Getters @NotNull PlacedBlock getPlacedBlock(); // Handler list @NotNull HandlerList getHandlers(); static HandlerList getHandlerList(); }

BlockRespawnEvent

Fired when a placed block respawns (after its respawn timer elapses). Extends Event (not cancellable, no player context).

public class BlockRespawnEvent extends Event { public BlockRespawnEvent( @NotNull PlacedBlock placedBlock, @NotNull BlockDefinition definition ); // Getters @NotNull PlacedBlock getPlacedBlock(); @NotNull BlockDefinition getDefinition(); // Handler list @NotNull HandlerList getHandlers(); static HandlerList getHandlerList(); }

8. Commands & Permissions #

Command: /mmoblock

Subcommand Permission Usage
block place mmoblock.admin /mmoblock block place <blockId> <x> <y> <z> [world] [facing]
block remove mmoblock.admin /mmoblock block remove <blockId> <x> <y> <z> [world]
block list mmoblock.admin /mmoblock block list [blockId]
block get mmoblock.admin /mmoblock block get <blockId|remover> (player only)
node place mmoblock.admin /mmoblock node place <nodeId> <x> <y> <z> [world]
node remove mmoblock.admin /mmoblock node remove <nodeId> <x> <y> <z> [world]
node list mmoblock.admin /mmoblock node list [nodeId]
node get mmoblock.admin /mmoblock node get <nodeId|remover> (player only)
reload mmoblock.admin /mmoblock reload [config|blocks|drops|lang|tools|nodes]

Coordinates support relative (~) and caret (^) notation if supported by the server version.

Permission Nodes

Permission Default Description
mmoblock.admin op Allows access to all /mmoblock admin commands.
