Block Definitions

Define custom mineable blocks with YAML — properties, drops, tools, models, display holograms, conditions, and more.

Block definitions are the core of MMOBlock. Each block is defined in a separate YAML file inside the blocks/ folder. These definitions control every aspect of the block: its appearance, behavior, drops, allowed tools, display holograms, sound effects, particles, and interaction conditions.

Block files are placed in plugins/MMOBlock/blocks/ and can be reloaded at runtime with /mmoblock reload blocks.

1. File Structure #

Each block is a single YAML file in the blocks/ directory. The file name becomes the block ID (without .yml). Here is the top-level structure:

# Top-level key = block ID exampleEntity: item: name: "Example Entity" material: diamond_ore respawnTime: 1 deadDelay: 5 randomLocation: enabled: true radius: 5 particleBreak: enabled: true source: type: VANILLA value: "minecraft:lava" sound: onClick: block.stone.hit onDead: block.stone.break onRespawn: block.stone.place breakAnimation: true hitbox: width: 1.2 height: 1.2 modelType: block: { ... } bdengine: { ... } allowedTools: - exampleTools conditions: - { ... } display: displayHeight: 2.1 lines: - { ... }

2. Item Configuration #

The item section defines the item that represents this block in inventories, the creative menu, and as the held item when placing.

Option Type Default Description
name String — Display name of the block item. Supports & color codes.
material Material — Bukkit Material for the item icon (e.g., diamond_ore, stone).

3. Timing & Location #

Control how the block behaves over time and where it can appear when using spawn randomization.

Option Type Default Description
respawnTime Integer — Seconds after the block is killed before it respawns.
deadDelay Integer — Seconds before the dead hologram disappears after the block is killed.
randomLocation.enabled Boolean false Whether to randomize the respawn location within a radius.
randomLocation.radius Integer — Radius in blocks for random respawn positioning.

4. Particles & Sound #

Configure visual and audio feedback during block interaction.

Section Option Type Description
particleBreak enabled Boolean Enable/disable break particles.
source.type String Particle source type: VANILLA.
source.value String Particle key (e.g., minecraft:lava).
sound onClick String Sound played on each click.
onDead String Sound played when the block dies.
onRespawn String Sound played when the block respawns.
breakAnimation Boolean Show the vanilla block break animation via packets.

5. Model Display #

MMOBlock supports several visual model types for rendering your blocks. Choose one or more under modelType.

Block Model

The simplest option — renders the block as a vanilla Minecraft block display.

modelType: block: enabled: true block: minecraft:diamond_ore

BDEngine Model

Native 3D model rendering via display-entity packets. Supports keyframe animations, collision fake-blocks, and scaling. See Models / BDEngine for full details.

modelType: bdengine: enabled: true model: iron_ore size: 2.0 collision: type: block block: minecraft:barrier position: - "0, 0, 0" onSpawn: name: spawn timeline_length: 0.5 mode: once onClick: name: click timeline_length: 0.5 mode: once

Schematic Model

Load .schem or .schematic files for complex structures with normal and dead variants.

modelType: schematics: enabled: true file: normal: "tree" dead: "dead/dead_tree" placeFacing: north adjustPos: normal: - "-14, 0, -15" dead: - "-14, 0, -15"

ModelEngine (External)

Compatibility with the ModelEngine plugin RR format.

modelType: modelEngine: enabled: false model: iron_crystal:1.0 onClick: name: example_onClick_animation lerpin: 0.1 lerpout: 0.1 speed: 1.0

6. Hitbox & Break Animation #

Define the interaction hitbox dimensions and whether to show the vanilla block-breaking texture animation.

Option Type Default Description
hitbox.width Double 1.0 Width of the interaction hitbox (blocks).
hitbox.height Double 1.0 Height of the interaction hitbox (blocks).
breakAnimation Boolean false Send block break animation packets while mining.

7. Display Hologram #

The display hologram renders floating text, items, and blocks above the block. It supports multiple lines with different content depending on the block state (active, being mined, dead).

Option Type Default Description
displayHeight Double 2.0 Height of the hologram above the block.
displayFacing.facing String "" Hologram facing mode: cardinal, intercardinal, or empty for always-facing.
displayFacing.distance Double 0 Distance from block center for facing offset.
displayFacing.detectRange Integer 16 Radius to detect the nearest player for facing.

Display Lines

Each line in the lines list defines a row in the hologram. Lines can contain text, items, or blocks, and change based on the block state.

display: displayHeight: 2.1 displayFacing: facing: cardinal distance: 0 detectRange: 16 lines: - line: 1 contents: item: minecraft:diamond click: hide - line: 2 contents: text: "<anim:wave:&1;&b>Example Entity</anim>" click: hide - line: 3 contents: text: "{condition_1}" click: "<anim:typewriter:&e;&6>Mining......</anim>" - line: 4 contents: text: "<anim:burn:#999bff;#ffe599>Click to Mine!</anim>" dead: "&7Respawns in: &c{respawn_time}s" click: "&7[&r{progress_bar}&7] &f(%mmoblock_progress%/%mmoblock_max_progress%)"

Content types per line:

  • text — Display text. Supports MiniMessage format, & color codes, placeholders, and animation tags.
  • item — Display an item (floating item model).
  • block — Display a block (floating block model).

State-specific fields:

  • text — Shown when the block is in ACTIVE state (idle, waiting to be mined).
  • click — Shown when the block is being MINED (progress state). Falls back to text if not set.
  • dead — Shown when the block is DEAD (destroyed, waiting to respawn). Falls back to text if not set.
  • Set to hide to hide this line entirely during that state.

Available placeholders:

  • {condition_<id>} — Shows the requirement text or met text for a condition.
  • {progress_bar} — Renders the progress bar defined in config.yml.
  • {respawn_time} — Countdown of remaining respawn seconds.
  • %mmoblock_progress% — Current mining progress (PlaceholderAPI).
  • %mmoblock_max_progress% — Maximum mining progress (PlaceholderAPI).
  • %mmoblock_respawn_time% — Remaining respawn time (PlaceholderAPI).

Animation tags:

  • <anim:wave:color1;color2>text</anim> — Smooth gradient wave animation.
  • <anim:typewriter:color1;color2>text</anim> — Typewriter reveal effect.
  • <anim:burn:primary;secondary>text</anim> — Burning/unburning effect.
  • <anim:colors:color1;color2;...>text</anim> — Cycling through multiple colors.

8. Allowed Tools #

The allowedTools list references tool definition IDs from the tools/ folder. These determine which items can mine this block, how many clicks are needed, and which drop tables are used.

allowedTools: - exampleTools - exampleToolsAxe

See the Tools documentation for how to define tool behaviors.

9. Conditions #

Conditions restrict who can mine a block. Each condition checks a PlaceholderAPI placeholder value against a comparator. If the condition is not met, the player cannot interact with the block.

conditions: - condition: 1 type: placeholder value: "%player_health%" operator: ">" compareTo: "10" placeholderText: require: "<anim:colors:#999bff;#148a87;...>Require HP 10</anim> &a✔" notMet: "<anim:colors:#999bff;#148a87;...>Require HP 10</anim> &c❌" sendTitle: "&cYou are too weak to mine this block!" sendSubtitle: "&7You need at least 10 health to mine this block."
Option Type Description
condition Integer Condition ID (referenced in display as {condition_<id>}).
type String Condition type. Currently only placeholder.
value String PlaceholderAPI placeholder to check (e.g., %player_health%).
operator String Comparison operator: >, <, >=, <=, ==, !=.
compareTo String Value to compare against.
placeholderText.require String Text shown when condition is met.
placeholderText.notMet String Text shown when condition is not met.
sendTitle String Title sent to player when condition fails (optional).
sendSubtitle String Subtitle sent to player when condition fails (optional).

10. Full Example #

Here is a complete block definition combining all features:

# blocks/exampleEntity.yml exampleEntity: item: name: "Example Entity" material: diamond_ore respawnTime: 1 deadDelay: 5 randomLocation: enabled: true radius: 5 particleBreak: enabled: true source: type: VANILLA value: "minecraft:lava" fallback: type: VANILLA value: "minecraft:stone" sound: onClick: block.stone.hit onDead: block.stone.break onRespawn: block.stone.place breakAnimation: true hitbox: width: 1.2 height: 1.2 modelType: block: enabled: true block: minecraft:diamond_ore bdengine: enabled: true model: iron_ore collision: type: block block: minecraft:barrier position: - "0, 0, 0" size: 2.0 onSpawn: name: spawn timeline_length: 0.5 mode: once onClick: name: click timeline_length: 0.5 mode: once allowedTools: - exampleTools conditions: - condition: 1 type: placeholder value: "%player_health%" operator: ">" compareTo: "10" placeholderText: require: "<anim:colors:#999bff;#148a87;...>Require HP 10</anim> &a✔" notMet: "<anim:colors:#999bff;#148a87;...>Require HP 10</anim> &c❌" sendTitle: "&cYou are too weak to mine this block!" sendSubtitle: "&7You need at least 10 health to mine this block." display: displayHeight: 2.1 displayFacing: facing: cardinal distance: 0 detectRange: 16 lines: - line: 1 contents: item: minecraft:diamond click: hide - line: 2 contents: text: "<anim:wave:&1;&b>Example Entity</anim>" click: hide - line: 3 contents: text: "{condition_1}" click: "<anim:typewriter:&e;&6>Mining......</anim>" - line: 4 contents: text: "<anim:burn:#999bff;#ffe599>Click to Mine!</anim>" dead: "&7Respawns in: &c{respawn_time}s" click: "&7[&r{progress_bar}&7] &f(%mmoblock_progress%/%mmoblock_max_progress%)"
