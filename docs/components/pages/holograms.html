Hologram System

Packet-based hologram system with text, items, blocks, animations, and proximity-aware facing — built into every block and node display.

MMOBlock uses holograms as the primary visual interface above blocks and nodes. They render floating lines of text, items, and blocks using packets, with state-aware content that changes when the block is idle, being mined, or respawning.

Holograms are rendered entirely via packets — no actual entities exist in the world. This makes them invisible to antigrief plugins and immune to entity limits, while being visible only to players who should see them.

1. Architecture #

MMOBlock uses a dual-backend hologram system:

Backend When Used Description
ECS Component Static holograms (no animation tags, no PAPI tokens) Uses an ECS HologramComponent that is synced via the HologramSystem.tick() loop. Most efficient for simple text.
Packet Backend Animated holograms (animation tags or PAPI placeholders) Per-tick text recomposition with packet updates. Used when holograms contain <anim:...> tags or PlaceholderAPI tokens.

The HologramRuntimeService manages the lifecycle: showActive(), showProgress(), showDead(), remove(), and clearAll().

2. Line Types #

Each line in a hologram can be one of three content types:

Type Config Key Description
Text text Display text with MiniMessage format, & color codes, placeholders, and animation tags.
Item item Shows a floating item model (e.g., minecraft:diamond).
Block block Shows a floating block model (e.g., minecraft:stone).

Line spacing and vertical offset can be tuned in config.yml (see Configuration).

3. Hologram States #

Each display line can show different content depending on the block's state. This is configured in the block definition's display.lines section.

State Field When Shown
ACTIVE text Block is idle, waiting to be mined.
PROGRESS click Block is being mined (shows progress). Falls back to text if not set.
DEAD dead Block is destroyed, waiting to respawn. Falls back to text if not set.

Set any state field to hide to completely hide that line during that state.

lines: - line: 1 contents: text: "<anim:wave:&1;&b>Block Name</anim>" # shown when ACTIVE click: hide # hidden during mining dead: "&cRespawning..." # shown when DEAD

4. Text Animations #

MMOBlock supports rich inline text animations within hologram text. These are processed by HologramAnimationUtil and HologramColorUtil.

Tag Example Effect
wave <anim:wave:&1;&b>text</anim> Smooth gradient wave animation across the text.
typewriter <anim:typewriter:&e;&6>text</anim> Typewriter reveal effect, character by character.
burn <anim:burn:#999bff;#ffe599>text</anim> Burning/unburning color sweep effect.
colors <anim:colors:#999bff;#148a87;...>text</anim> Cycles through the listed colors.

MMOBlock also supports legacy [#]ANIM: pattern from DecentHolograms for backward compatibility.

5. Placeholders #

Hologram text supports several built-in placeholders:

Placeholder Description
{condition_<id>} Shows the condition requirement text or met text for the condition with the given ID.
{progress_bar} Renders the progress bar defined in config.yml (progressbar section).
{respawn_time} Countdown of remaining seconds until the block respawns.
{block_lists} Auto-populated block list for nodes (shows active/dead child blocks).
{block_name} Display name of a child block (used within node block list templates).
{respawn_times} Remaining respawn time for a child block (used within node block list templates).
%mmoblock_progress% PlaceholderAPI — current mining progress.
%mmoblock_max_progress% PlaceholderAPI — maximum mining progress.
%mmoblock_respawn_time% PlaceholderAPI — remaining respawn time.
PlaceholderAPI placeholders require the PlaceholderAPI plugin to be installed on your server. Without it, PAPI tokens will show as-is.

6. Facing & Proximity #

Holograms can optionally face the nearest player within a detection range. This creates a "billboard" effect where the hologram always faces the viewer.

Option Type Description
facing String cardinal (N/S/E/W), intercardinal (NE/NW/SE/SW), or empty for always facing.
distance Double Distance from the block center to offset the hologram's facing pivot.
detectRange Integer Radius in blocks to search for the nearest player (default 16).

7. Configuration #

Hologram spacing and performance settings are configured in config.yml:

hologram: packet: maxUpdatesPerTick: 200 spacing: text: 0.25 item: 0.30 block: 0.30 offset: text: 0.00 item: 0.00 block: 0.00
Option Type Default Description
maxUpdatesPerTick Integer 200 Maximum hologram packet updates per tick (performance cap).
spacing.text Double 0.25 Vertical spacing between text lines (blocks).
spacing.item Double 0.30 Vertical spacing for item display lines.
spacing.block Double 0.30 Vertical spacing for block display lines.
offset.* Double 0.00 Additional vertical offset for each line type.
