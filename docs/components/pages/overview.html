Getting Started #

Follow these steps to install MMOBlock on your server:

  1. 1 Build the project
    $ ./gradlew build
  2. 2 Copy the JAR — Copy plugin/build/libs/MMOBlock.jar to your server's plugins/ folder
  3. 3 Start the server — The plugin will generate default configuration files inside plugins/MMOBlock/
  4. 4 Configure — Edit config.yml and the definition files in blocks/, drops/, tools/ to match your needs
MMOBlock automatically downloads its runtime libraries (HikariCP, H2, MySQL connector, Gson, Caffeine, MiniMessage) on first startup via MMOBlockLoader.
